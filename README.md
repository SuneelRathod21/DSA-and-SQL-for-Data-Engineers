## 📌 About This Repository

This repository focused on **pattern-based DSA**, **SQL fundamentals**, and **PySpark internals** required for Data Egineers.  
The goal is to build strong problem-solving skills and understand how data systems work **at scale**.

## 📚 Topics Covered
- **DSA:** Two Pointers, Sliding Window, HashMap, Arrays & Strings, Linked List patterns  
- **SQL:** CTEs, Subqueries, Indexing, CASE WHEN, Window Functions  
- **PySpark:** Architecture, DataFrame API, Joins, Shuffle & Partitioning, Performance Tuning

## 🎯 Why This Repo
Designed to help a **Data Engineer** write efficient, scalable solutions, understand performance bottlenecks, and prepare confidently for technical interviews.
